# Dungeon Dilemma  
A Dungeon Builder and Crawler Roguelike where you can construct your own dungeon or raid one designed by your friends. Vie for victory, defeat minions, and evade traps as a party of up to 4 Challengers, or create the most diabolical dungeon imaginable as the Dungeon Boss!

## Installation Instructions
Clone this repository onto your device. Ensure you have the correct version of Unity Editor installed and either VS Code or another IDE of your choice. You may need to change your default IDE inside Unity preferences.

To clone this repository, open github desktop, and click in the top left.

Select `Add > Clone Repository > Github` and search for the repository name.

## How to Commit to this Repository
Save your changes and use either command line or github desktop to push to the branch you are working on. For merges to main, open a request and wait for it to be checked and approved, unless otherwise specified. Do your best to label the commit properly so others may understand the content of the changes.

### Folder Structure FAQs
- `Art vs Temp Art` Official/final art should be placed in `Art`. Any programmer or trial art should go in `Temp Art`.  
- `Scriptables vs Scripts` HLSL and C# code should be placed into the `Scripts` folder. Scriptable objects (the Unity asset) should be placed into `Scriptables`. Please sort further by category or make new folders inside as needed.  
- `Font` All custom fonts should be placed into this folder. DO NOT place font assets into the `TextMesh Pro` folder.  
- `Editor` This folder is for Unity editor tools and will not be included in any builds. Use this for scripts to automate in-editor tasks.
